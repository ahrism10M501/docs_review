# 피지컬 AI 논문 렌즈

로봇 학습·조작·보행·휴머노이드·VLA·월드 모델 논문을 읽을 때 쓰는 질문 목록이다. 카드와 비교표의 축이 되고, paper-deep-reader에는 `domain-lenses.md`의 "计算机科学与人工智能" 렌즈와 함께 이 파일을 주 렌즈로 준다. 논문에 답이 없으면 "논문에 없음"으로 적는다. 빈칸도 정보다.

## 1. 무엇을 풀었나

- **문제 유형:** 조작(집기·삽입·변형체·양팔·손재주), 보행·전신 제어, 내비게이션, 이동+조작, 범용 정책(VLA·파운데이션 모델), 월드 모델·시뮬레이션, 표현 학습, 데이터 수집 시스템.
- **학습 방식:** 모방학습(BC·Diffusion·flow·ACT 계열), 강화학습(on/off-policy, sim에서 학습 후 전이), 오프라인 RL, 사전학습+미세조정, 모델 기반 계획, 고전 제어와 결합.
- **입력:** RGB / 깊이 / 점군 / 고유감각(관절·IMU) / 촉각·힘 / 언어 지시. 카메라 수와 위치(손목·고정).
- **출력:** 관절 위치·토크, 엔드이펙터 포즈, 액션 청크 길이, 제어 주기(Hz), 하위 제어기(PD·임피던스·IK)가 무엇인지.

## 2. 어떤 몸과 어떤 세계에서

- **로봇:** 기종, 자유도, 그리퍼·손, 센서. 기종이 바뀌어도 되는지(cross-embodiment) 주장하는지.
- **시뮬레이터:** Isaac Sim/Lab, MuJoCo, PyBullet 등과 버전. 도메인 랜덤화 범위, 접촉·마찰 모델.
- **실물 실험:** 했는가, 몇 개 과제, 과제당 시도 횟수, 초기 상태를 어떻게 바꿨는가. sim 결과만으로 실물 주장을 하지 않는지.

## 3. 데이터

- 시연 수, 수집 방법(텔레오퍼레이션 장치·VR·키네스테틱·스크립트), 수집 시간과 사람 수.
- 공개 데이터셋(Open X-Embodiment, DROID 등)을 썼다면 어떤 부분집합인지.
- 학습·평가 분리: 같은 물체·장면·초기 상태가 겹치지 않는지.

## 4. 평가가 주장을 받쳐 주는가

- **성공 기준:** 누가 어떻게 판정했는지(사람·자동), 부분 성공을 어떻게 셌는지.
- **시도 수와 불확실성:** 과제당 10회 성공률 차이 10%p는 우연일 수 있다. 신뢰구간·시드 수가 있는지.
- **베이스라인:** 같은 데이터·같은 하드웨어·같은 튜닝 노력으로 돌렸는지, 원 논문 수치를 옮겨 왔는지.
- **일반화 축:** 새 물체 / 새 배치 / 새 장면·조명 / 새 지시 / 방해·외란 / 새 로봇. 각각 따로 측정했는지.
- **제거 실험(ablation):** 핵심 구성요소를 빼면 얼마나 떨어지는지. 성능이 구조 덕인지 데이터·규모 덕인지.
- **실패 사례:** 실패 모드를 보여 주는지. 영상이 고른 성공만 보여 주는지.
- **비용:** 학습 GPU·시간, 추론 지연, 실시간 제어 가능 여부.

## 5. 재현과 활용

- 코드·가중치·데이터 공개 여부와 라이선스.
- 우리 환경(가진 로봇·시뮬레이터·GPU)에서 돌리려면 무엇이 필요한지.
- 이 task의 목표와 연결: 가져다 쓸 수 있는 아이디어, 따라 해 볼 최소 실험.

## 6. 자주 하는 오독

- 시뮬레이션 성공률을 실물 성능으로 읽기.
- "범용"·"제로샷"을 평가 범위보다 넓게 읽기.
- 데이터 규모 차이를 방법 차이로 읽기.
- 데모 영상 몇 개를 정량 평가로 읽기.
- 제어 주기·지연을 안 보고 동적 과제 성능을 비교하기.
